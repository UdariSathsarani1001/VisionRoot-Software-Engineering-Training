**Objective:** Create a usable interface with clear component boundaries and states.

## What I learned

- **Page and component responsibilities:** pages compose components, feature components know about requests, and generic UI components contain no request logic.
- **Feature-based folder structure:** keeping request code together in `features/requests/` makes it easy to find and change.
- **Forms and client-side validation:** controlled inputs, visible field errors, and why the server must still validate everything.
- **Accessible labels:** every input needs a label, and error messages should be announced with `role="alert"`.
- **Loading, empty, success and error states:** a data view should always tell the user what is happening.
- **shadcn/ui:** component source is copied into the repository, so it is reviewable, and it needs Tailwind CSS.

## What I implemented

- Request list with a status filter and loading, empty and error states.
- Create-request form with client-side validation (title 3 to 100 characters, description 1 to 1000, category and priority required) and success and error feedback.
- One API client module (`src/lib/api.ts`) with mock data, following `docs/api-contract.md`.
- Shared state components (loading, empty, error) and status and priority badges.
- shadcn/ui components styled with Tailwind CSS.
- Responsive layout and accessible labels.
- Request details page (stretch).

## Problem encountered

shadcn/ui needs Tailwind CSS, but I had created the frontend without Tailwind on Day 03.


## How I investigated it

I checked the shadcn/ui installation steps and found that Tailwind CSS must be configured in the project before the components can be added. I compared that with the `create-next-app` options I had used on Day 03.

## Root cause

I created the app with Tailwind turned off, because the plan at that point did not include a UI library, so the project had no Tailwind configuration for shadcn/ui to build on.

## How I fixed it

I added Tailwind CSS to the existing frontend following its Next.js guide, then ran the shadcn/ui setup and added the components I needed. I updated the README setup notes and recorded the decision in `notes.md`.
